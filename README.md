# 📌 기능 요구 사항
## 1. 입력 기능
- [X] 사용자가 경주할 자동차 이름들을 입력한다(쉼표로 구분)
- [ ] 사용자가 시도할 횟수를 입력한다.
<br>

## 2. 유효성 검사 기능
- [x] 입력된 자동차 이름이 5자를 초과하는 경우 IllegalArgumentException 발생
- [x] 입력된 자동차 이름이 비어있거나, 공백만 있는경우 IllegalArgumentException 발생
- [ ] 시도할 횟수의 숫자가 숫자가 아니거나 1 미만의 숫자일 경우 IllegalArgumentException 발생
- [ ] 시도할 횟수의 숫자가 공백으로 들어오는 경우 IllegalException 발생
<br>
- 
## 3. 게임 매인 기능
- [ ] 각 자동차 이름기반으로 car 객체 생성(이름 + 현재 위치)
- [ ] car 객체는 무작위 값이 4 이상이 나오면 1칸 전진한다.
- [ ] car 객체는 무작위 값이 3 이하일 경우 멈추고 현재 위치를 유지한다.
- [ ] 모든 시도가 끝난 후, 가장 멀리 이동한 차를 우승자로 선정한다
<br>
- 
## 4. 출력 기능
- [ ] 각 시도가 끝날 때마다 현재 모든 자동차 위치를 '-'(1칸)으로 표시한다. (이름 : -- 형태)
- [ ] 최종 우승자를 '최종 우승자 : 이름' 형식으로 출력한다. (여러명인 경우 이름칸에 쉼표로 구분)
